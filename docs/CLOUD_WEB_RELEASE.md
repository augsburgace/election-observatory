## Operations and limits

The active workflow checks sources and publishes on a two-hour GitHub schedule. The Mac can be off. GitHub can delay or miss jobs, and a full build can take substantial time; publication time and source reporting dates are separate clocks. The previous validated website stays available during updates. [Cloud operating instructions](CLOUD_UPDATES.md) cover manual refreshes, checkpoint retention, resource gates and verified rollback.

Source code was published through a clean reviewed distribution rather than exposing private Git history. Public checkpoints exclude personal research, jobs, correction reasons, credentials and original voter-file archives. The two fixed Census references and factual polling captures use narrow validation rules. These aggregate checkpoints are not backups of the private local application.
