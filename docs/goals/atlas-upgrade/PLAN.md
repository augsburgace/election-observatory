# Expanded atlas execution contract

Goal: implement the user-approved colorful, deeply detailed 50-state/all-office atlas. Use detail-on-demand, bright editorial canvas/navy navigation, complete navy theme, local Source Sans 3/Source Serif 4, semantic map/chart encodings and inspectable original evidence.

Truth owner: archived original source documents and validated revisioned participation, result and context records. Shared backend analysis owns quantitative calculations; shared frontend map specifications own rendering meaning.

Boundary: provider -> immutable archive -> normalized SQLite records -> versioned catalog/query APIs -> coordinated map/chart/table/brief/export.

Cutover: upgrade the running local application; preserve v1 URLs and saved investigations. No public deployment, paid services, external AI APIs, private-record exports, invented data or forecasts without validation.

Required corrections: name joins, radius/area scaling, map-renderer parity, quantitative legends/theme, invalid Maine request trajectory, incompatible pace. Never silently replace pinned filters.

Data scopes: participation belongs to election/method; returns belong to contest/option/round; context belongs to geography/estimate period. Contest votes are not total ballots. Typed first-class catalog/results/geography/context models retain source/hash/chronology and boundary/denominator evidence.

Research surfaces: Today, Atlas, States, Elections, Research; durable place/contest/candidate pages; long state overview; universal search; linked selections/focus/brush; original polls and scenario tools; on-demand progress; complete tables/export alternatives.

Acceptance: every state has substantive sourced core; no unverifiable filled polygons; consistent map/chart/table/brief/export; exact saved-view compatibility; real job progress/outage retention; cached feedback<500ms and cached opening<3s target. All-office records are a verified source catalog, not an unsupported claim of every local race. Large geometry loads by area; forecasts remain gated.
